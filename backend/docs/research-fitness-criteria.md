# 국민체력100 평가 기준 조사 기록

확인일: 2026-09-23. 이 문서는 운영 기준의 출처·적용 범위와 미확보 범위를 기록한다. 구현의 계산 등급은 아래 공식 수치에 대한 **개별 검사 기준 충족 등급**이며 국민체력100 종합 인증등급이나 인증서가 아니다.

## 2. 보존한 검증 데이터

[nfa100-adult-2025-0027.json](research/nfa100-adult-2025-0027.json)에 54행과 468개 코드별 임계값을 Decimal 문자열로 보존했다. 동일한 공식 VO₂max 열을 `treadmill_vo2max`와 `step_test_vo2max`에 각각 연결하므로 원문 수치 칸 414개보다 코드별 값 개수가 많다. HTML/PDF SHA-256, 출처, 단위, 비교 연산, 확인일, 공식 시행일을 포함한다. 이 파일은 검증 원자료이며 가상 테스트 기준이 아니다.

- 연령구간: 19~24, 25~29, 30~34, 35~39, 40~44, 45~49, 50~54, 55~59, 60~64세. 양 끝을 포함한다.
- 성별은 공식 표의 남·여를 `male`·`female`로 대응한다. 성별 미상은 추정하지 않는다.
- 측정 시점의 만 나이를 사용한다. 기존 API의 `ageAtMeasurement`는 사용자가 명시한 당시 만 나이이며 현재 계정 나이에서 유추하지 않는다. 생년월일을 받지 않는 기존 계약에서 이를 새로 요구하지 않는다.
- 기준에 도달한 값을 포함한다. 횟수·거리·VO₂max·상대악력·체공시간은 `>=`, 소요시간·반응시간은 `<=`로 비교한다. 1등급부터 검사하여 가장 좋은 충족 등급을 반환한다.
- 별도의 반올림 규정을 확인하지 못했다. 저장 Decimal 값을 표의 Decimal 임계값과 그대로 비교하며 평가 전에 반올림하지 않는다. 다음 목표까지의 차이도 Decimal 차이로 제공한다.
- **원문 차이:** 남 60~64세 3등급 앉아윗몸앞으로굽히기 PDF에는 `2,3`, 현재 국민체력100 HTML에는 `2.3`으로 표시된다. 데이터는 현재 공식 HTML의 `2.3`을 사용하며 차이를 숨기지 않는다.

## 3. 자가측정 프로토콜과 미확보 기준

같은 체력 요인에 속한다는 이유로 기준을 공유하지 않는다. 프론트의 검사 코드 선택은 아래 측정 방법을 따랐다는 입력 계약이다. 기관이 사용자 수행을 인증했다는 뜻은 아니다.

| 검사                       | 검증한 측정 방법                                                                                                                                                          | 등급 수치 확보 상태                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `cross_sit_up`             | 무릎을 굽혀 눕고 발목 고정, 팔을 가슴 앞에서 교차하여 손을 어깨에 둔다. 일으켰을 때 팔꿈치가 허벅지에 닿고 누울 때 등·어깨가 바닥에 닿도록 하며 1분 성공 횟수를 기록한다. | 동일한 성인 교차윗몸일으키기 공식 기준 적용 가능                               |
| `self_curl_up`             | 팔을 편 채 손을 허벅지에 두고 3초 간격 신호에 맞춰 말아 올리고 내려온다. 머리가 바닥에 돌아온 때 1회이며 발이 뜨거나 신호를 놓치면 종료한다.                              | 성인 자가측정 프로토콜은 확인했으나 이에 맞는 공식 수치 등급표를 확보하지 못함 |
| `ymca_recovery_heart_rate` | 30cm 스텝박스에서 96bpm 박자로 3분 수행하고 1분 쉰 뒤 10초 동안 맥박을 세어 6배한 bpm을 기록한다.                                                                         | 이 회복 시점·단위·연령·성별에 맞는 국민체력100 공식 등급 임계값 미확보         |
| `sit_and_reach`            | 무릎을 펴고 앉아 발뒤꿈치에 줄자 30cm 지점을 맞춘다. 앞으로 뻗은 지점에서 30cm를 뺀 부호 있는 거리를 기록한다.                                                            | 성인 앉아윗몸앞으로굽히기 공식 cm 기준 적용 가능                               |

`self_curl_up`에는 교차윗몸일으키기 또는 청소년 `curl_up`의 기준을 적용하지 않는다. YMCA bpm에는 `step_test_vo2max`의 단위나 등급을 적용하지 않으며 회귀식으로 산소섭취량을 만들어내지 않는다. 프론트가 bpm 변환을 끝내 전송하므로 서버에서 다시 6배하지 않는다. 앉아굽히기도 기준선 변환이 완료된 cm를 전송하며 서버는 다시 30을 빼지 않는다.

미확보 판단은 “그런 기준이 존재하지 않는다”는 단정이 아니다. 공식 자가측정 이용 안내에는 회원 결과 확인 기능이 설명되어 있으나, 공개 측정항목·인증기준·공식 고시 및 검색으로 접근한 일차 출처에서 위 두 검사의 호환되는 수치표와 개정 정보를 검증하지 못했다. 2026-09-23 구현에서는 두 항목 모두 저장을 허용하고 `criteria_unavailable`, 계산 등급 `null`, 제공 불가 사유를 반환했다. 목표값도 만들지 않았다.

2026-09-24 사용자 결정으로 `self_curl_up`의 신규 입력을 제외했다. 기존 기록과 과거 카탈로그는 보존하며 과거 항목 수정 시에도 위 미확보 사유를 유지한다. 별도 청소년 종목 `curl_up`은 제외하지 않는다. YMCA bpm은 기존 저장·평가 불가 정책을 유지한다. 이 변경은 제품 입력 범위의 정정이며, 새로운 공식 기준을 검증했다는 의미는 아니다.

## 4. 평가 모델에 대한 적용 원칙

1. 기준의 식별 키는 검사 코드 + 프로토콜 + 단위 + 측정 당시 연령구간 + 공식 성별 구간 + 적용 시점이다. 이름 유사성이나 축으로 기준을 찾지 않는다.
2. 값이 있고 성별 등 필수 판정 정보가 없으면 `insufficient_information`; 호환되는 검증 기준이 없으면 `criteria_unavailable`로 구분한다.
3. 미측정 항목 행을 만들지 않는다. 기준 미달은 숫자 0등급이 아니며, 측정한 0회는 정상적인 값으로 평가한다.
4. `reportedGrade`는 사용자 원문이다. 계산 등급, 기준 식별자, 실제 적용 연령·성별, 평가시각, 기록 revision을 별도로 보존한다.
5. 종합 인증은 별도 복수조건·기관 인증 문제이다. 부분 기록이나 여섯 축의 최상 등급을 종합 인증등급으로 합성하지 않는다.
6. 기존 기록은 일괄 채우거나 재평가하지 않는다. 신규 생성·명시적 수정에서 평가하며 이전 snapshot이 없는 기록은 미평가 상태를 구분한다.

## 5. 조사 데이터 확인

- JSON 54행, 남/여 각각 9연령구간, 원문에 존재하는 등급별 필드 수를 확인했다.
- PDF에서 별도로 추출한 414개 원문 수치와 HTML 데이터를 기계적으로 대조했다. 위에 기록한 `2,3`/`2.3` 소수점 표기 차이 외에는 모두 일치했다.
- 같은 성별·연령·종목의 1→2→3 임계값이 판정 방향과 일관되게 완화되는지 Decimal 비교로 검사했다.
- 공식 PDF를 렌더링해 성별 셀 병합, 열 순서, 2등급의 페이지 연결, 3등급의 운동체력 열 부재를 확인했다.
- 이 조사의 수치 기준은 성인에 한정한다. 기존 청소년 저장 지원은 유지하지만 청소년 평가 기준은 이번 검증 데이터에 등록하지 않는다.
