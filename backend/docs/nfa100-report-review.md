# 국민체력100 체력평가지와 등급 입력 검토

확인일: 2026-09-19. 상태: 공개 자료 조사 및 입력 방식 제안. 등급 전용 입력이나 자동 판정을 구현한 문서가 아니다.

## 1. 이번 사용자 결정

- 측정 지원 연령 확대는 MVP 이후에 개발한다. 현재 지원 범위인 만 13–64세를 유지한다.
- 운동 영상 저장·조회, 추천, 내부 가중치 갱신 연계는 현재 측정 데이터 단계 이후에 진행한다.
- 결과지 형태를 조사해 등급만 입력하는 기능의 필요성을 검토한다. 아래 입력 방식은 조사에 따른 추천이며 새로운 사용자 확정 사항으로 간주하지 않는다.

## 2. 확인한 결과지 형태

공공기관 경영정보 공개시스템 ALIO에 게시된 코레일테크 채용 첨부자료의 국민체력100 서류 예시를 확인했다. PDF 5쪽은 체력인증서, 6–7쪽은 성인 체력평가지 예시다. 개인정보 등을 가린 안내용 자료이므로 양식 확인에 사용하며, 기재 수치를 자동 판정의 정답 데이터로 사용하지 않는다.

| 문서·영역   | 확인한 내용                                   | 서비스에서의 구분                 |
| ----------- | --------------------------------------------- | --------------------------------- |
| 체력인증서  | 종합 인증등급과 인적 사항·일자                | 측정 회차의 원문 종합등급         |
| 체력평가지  | 성별·나이·측정일, 신장·체중, 종합등급         | 측정 당시 정보와 실제 측정값      |
| 항목별 평가 | 실제 측정 수치, 비교 그래프, 항목별 평가 표기 | 검사별 원문 수치와 원문 평가      |
| 참고표      | 측정값, 백분위, 1·2·3등급 기준값, 평균값      | 서로 다른 의미를 가진 값으로 구분 |

항목별 평가에는 숫자 등급 외에 `참가` 표기도 보인다. 참고표의 괄호 안 백분위는 측정값 자체나 종합 인증등급이 아니다. 현재 모든 연령·센터의 최신 결과표 양식을 대조한 것은 아니며, 청소년 결과표와 추가 보조값은 후속 대조가 필요하다.

출처: [ALIO 공개 PDF](https://www.alio.go.kr/download/download.json?fileNo=3030277), PDF 5–7쪽.

## 3. MVP 입력 방식 추천

**측정 수치 입력을 기본으로 유지하고, 결과지에 적힌 항목별 평가와 종합 인증등급은 선택적으로 함께 저장하는 방식**을 추천한다. 공개 예시에는 수치가 있으므로 등급만 저장해 정보를 줄일 필요가 없다. 종합등급 하나만으로 부족한 체력요인을 역으로 추정할 수도 없다.

- 현재처럼 유효한 측정 수치 1개 이상이면 부분 저장한다. 나머지는 미입력 상태로 유지한다.
- 항목의 `value`·`unit`, 항목 원문 평가인 `reportedGrade`, 회차 원문 종합등급인 `reportedOverallGrade`를 구분한다.
- 등급만 입력하는 별도 모드는 MVP 우선순위를 낮추는 것을 제안한다. 인증서만 가지고 있는 사용자의 수요가 확인되면 수치가 없는 별도 입력 계약을 검토한다. 현재 API는 등급만으로 저장할 수 없다.
- 기존 데이터 협업 초안의 항목별 `1 | 2 | 3`은 미입력과 `참가` 같은 결과지 표기를 충분히 표현하지 못한다. 원문 평가와 알고리즘용 정규화 값을 구분하는 계약이 필요하다.
- 종합 인증등급이 6등급까지 있다는 이유로 모든 항목별 평가를 `1 | 2 | 3 | 4 | 5 | 6`으로 바꾸지는 않는다. 두 등급은 의미와 판정 규칙이 다르다.

현재 DB·API는 두 원문 등급 필드를 선택적 문자열로 보존한다. 이번 조사로 DB 스키마나 필수 측정값 조건을 변경하지 않는다.

## 4. 자동 판정에 필요한 공식 자료

자동 판정에는 공식 기준 자료가 필요하다. 사용자 측정값만 수집하거나 데이터 담당자의 영상 전처리 결과를 기다린다고 판정 규칙이 생기는 것은 아니다. 다음 근거를 별도로 확보·검증해야 한다.

1. 측정 당시 나이·성별·검사 방법별 수치 기준과 단위.
2. 높은 값 또는 낮은 값 중 어느 쪽이 기준을 충족하는지와 경계값 포함 여부.
3. 종합등급을 결정하는 건강체력·운동체력·신체조성 조합 조건.
4. 기준의 시행일·버전과 과거 측정일에 적용할 규칙.
5. 대체검사 처리, 미측정·미입력·간편측정처럼 근거가 부족한 경우의 처리.

공식 안내상 청소년·성인의 종합 인증등급은 2025-06-02부터 1–6등급으로 확대되었다. 시행 전 결과에 소급 적용되지 않는다. 따라서 종합등급을 1–3으로 제한하거나 과거의 참가 결과를 임의로 4–6등급으로 바꾸면 안 된다. [공식 변경 공지](https://nfa.kspo.or.kr/community/board/selectNoticeView.kspo?contSn=37812&menuId=A05_B01)

공개 수치 기준표와 종합 인증 조건은 별도 자료다. 특히 4–6등급을 각 검사에 세 개의 추가 경계값이 있는 것으로 해석하지 않는다. [공식 수치 기준표](https://nfa.kspo.or.kr/reserve/0/selectMeasureGradeItemListByAgeSe.kspo), [공식 인증단계·조합 조건](https://nfa.kspo.or.kr/intro/step.kspo)

서비스 설계상 판정에 필요한 값이 없으면 평가 불가 사유를 남긴다. 미입력을 기준 미달이나 6등급으로 취급하지 않는다. 자동 계산 결과는 원문 등급과 분리하고 적용한 규칙 버전·입력 revision을 기록한다. API 버전, 검사 카탈로그 버전, 판정 기준 버전도 각각 별도로 관리한다. 서비스 계산 결과를 기관에서 발급한 인증 결과로 표시하지 않는다.

1·2·3등급 경계값만으로 정확한 백분위를 복원할 수는 없다. 백분위 계산은 별도 공식 분포 자료와 계산 방법이 확인될 때만 검토한다.
