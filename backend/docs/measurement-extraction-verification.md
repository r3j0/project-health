# 사진 추출 API 검증 기록

검증일: 2026-09-21. 작업 브랜치: `feat/backend/db-user`. 변경 범위: `backend/`만. 테스트 실행 환경: Node.js 26.7.0, PostgreSQL 전용 테스트 DB의 임시 스키마. 실제 키·개인정보·사진 표본은 fixture에 사용하지 않았다.

## 실행한 검사

| 명령·검사              | 결과                                         |
| ---------------------- | -------------------------------------------- |
| `npm run db:validate`  | Prisma 스키마 검증 통과                      |
| `npm run db:generate`  | Prisma Client 생성 통과                      |
| `npm run format:check` | 서식 검사 통과                               |
| `npm run lint`         | 타입 인식 린트 통과, 린트 경고 없음          |
| `npm run typecheck`    | TypeScript 검사 통과                         |
| `npm test`             | 5개 파일, 108개 단위 테스트 통과             |
| `npm run test:e2e`     | 10개 파일, 182개 PostgreSQL 통합 테스트 통과 |
| `npm run build`        | Nest 빌드 통과                               |
| `git diff --check`     | 공백·패치 형식 검사 통과                     |

위 절차를 묶은 `npm run check` 전체 실행이 성공했다. 초기 실행 중 발견된 다중 파일 거절 후 버퍼 정리 오류는 수정했고 해당 통합 테스트가 통과했다. 로컬 DB 접근이 샌드박스에서 차단되어 허용된 실행 환경에서 통합 테스트를 다시 실행했다. 테스트 도우미는 임시 스키마에 7개 기존 마이그레이션을 적용하고 두 번째 적용에서 미적용 변경이 없음을 확인한 후, 완료 시 해당 스키마를 삭제한다.

일부 기존 DB 경로에서 `pg` 드라이버의 동시 `client.query()` 사용에 관한 DeprecationWarning이 출력됐다. 현재 검사 실패는 아니며 린트 경고와는 별개다. 이 작업에서는 기존 Prisma/pg 동작을 변경하지 않았다.

## 자동 검증 내용

- 실제 JPEG·PNG·WebP 디코딩, MIME 위장, 비이미지, 손상 픽셀, 파일 크기, 가로·세로 및 총 픽셀 한도, 애니메이션 거절, 메타데이터 제거.
- 실제 DB 카탈로그 최신·명시 버전 선택, 원문 단위와 후보 단위 검증, Decimal 문자열 정밀도·음수·0, 단위 동의어, 악력과 상대악력 구분, 수치 제약, 중복·상충·여러 시도·연령 경계.
- 전체 판독 불가, 비대상, 등급 전용, 여러 사람/회차, 부분 성공, 공란·판독 불가 행·미탐지 코드 구분, 날짜·나이·성별 오류와 추가 입력 안내.
- 실제 프롬프트·카탈로그·이미지·strict 스키마 전달, 모델 거절, 잘린/미완료 응답, 스키마 오류, 응답 크기 제한, 타임아웃·취소, 외부 429·5xx·네트워크 실패, 재시도 없음, 로그·오류 원문 비노출.
- 실제 Bearer 인증·세션 폐기, 키/모델 미설정 시 추출만 비활성, 사용자별 분·일 호출 제한, 다른 사용자 제한 분리.
- 추출 성공·실패 전후 측정 기록·생성 요청 이력·계정·온보딩 불변, 사용자 확인 결과를 기존 저장 API에 넣었을 때만 저장·온보딩 변경, `manual` 출처·Idempotency-Key·ETag 보존.
- 기존 측정 CRUD·인증·소유권·부분 저장·정밀도·수정 충돌·사용자 기능 회귀 테스트.

## 실제 외부 호출과 남은 검증

**실제 OpenAI API 호출은 수행하지 않았다.** 작업 환경에 `OPENAI_API_KEY`·`OPENAI_OCR_MODEL` 설정이 없었고, 호출용 결과지 사진도 제공되지 않았다. 자동 테스트에서는 OpenAI transport를 테스트에서만 대체했다. 운영 코드에 테스트 대역·예시 성공 결과는 없다.

남은 항목은 서버 키 주입, 실제 계정에서 이미지·Structured Outputs 지원 모델의 호출 권한 확인, 사용이 허용된 결과지 표본으로 [추출 curl 및 확인 후 저장 흐름](measurement-extraction-api.md)을 실행하는 것이다. 한글·작은 글자·기준표 혼동·다양한 센터 양식·사진 속 지시문에 대한 실제 모델 정확도는 이 자동 테스트의 보장 범위가 아니다.

## 최종 확인
