실제 전용 테스트 DB의 임시 스키마를 사용하고 종료 시 해당 스키마만 정리했다. 개발·운영 DB에 마이그레이션을 적용하지 않았다. 테스트 연결은 샌드박스의 localhost 연결 차단 후 승인된 실행으로 진행했다.

중간 실행에서 기존 `auth.e2e-spec.ts`의 잘못된 JWT 알고리즘 검사가 예상 401 대신 404를 받아 실패했다. 후속 조사에서 macOS와 Supertest의 wildcard 바인딩 때문에 다른 loopback 서버의 응답을 받을 수 있음을 실제 자동 포트 배정으로 재현했다. HTTP 테스트 초기화 9곳을 명시적 IPv4 loopback 바인딩으로 수정했으며 인증 코드·기대 상태·재시도 정책은 변경하지 않았다. 최초 실패의 상대 프로세스는 당시 로그가 없어 특정하지 못했다. [분석·재현·수정 검증](auth-test-failure-analysis.md)을 참고한다.
