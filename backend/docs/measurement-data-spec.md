# 국민체력100 측정 데이터 명세

작성·공식 자료 확인일: 2026-09-19. 상태: **입력·CRUD·종목 평가 구현**. 2026-09-23 확장 계약은 [간이측정·평가 API](measurement-evaluation-api.md)가 우선한다. 호출 계약과 직접 테스트는 [측정 API 안내](measurements-api.md)를 따른다.

이 문서는 실제 배포할 웹앱의 측정 결과 입력 구조를 정의한다. 제품 정책은 아래 사용자 결정에 따르며, 필드명·검증·저장 구조는 이를 구현하기 위한 기술 설계다. 평가 점수·등급 산출·운동 추천 규칙은 별도 단계에서 검증한다.

## 1. 확정 범위

| 항목      | 결정                                                                           | 근거                                           |
| --------- | ------------------------------------------------------------------------------ | ---------------------------------------------- |
| 제품 형태 | 실제 배포·운영할 웹앱. 결과를 맞추기 위한 하드코딩 금지                        | 2026-09-19 사용자 지시                         |
| 입력 대상 | 측정 당시 만 13–18세 청소년, 만 19–64세 성인의 국민체력100 결과                | 기존 합의 유지                                 |
| 입력 방식 | 직접 입력 또는 사진 추출 초안을 사용자가 확인·수정한 뒤 기존 API로 저장        | 2026-09-21 사용자 결정                         |

| 측정 분류 | 공식 대분류·요인·검사 항목을 모두 반영                                         | 2026-09-19 사용자 지시 및 아래 공식 자료       |

서비스 전체의 가입 가능 연령과 측정 기록의 지원 연령은 별개다. 여기서 13–64세는 측정 결과 입력·분석 범위다.

2026-09-19 추가 결정: **지원 연령 확대는 MVP 이후**, **운동 영상·추천·내부 가중치 갱신 연계는 현재 측정 데이터 단계 이후**에 진행한다. 결과지 조사에 따른 입력 방식 제안과 자동 판정에 필요한 근거는 [체력평가지 검토](nfa100-report-review.md)에 정리한다. 등급만 입력하는 별도 기능은 아직 확정·구현하지 않았다.

2026-09-21 결정으로 OCR 제외 정책은 OpenAI 사진 추출 연동에 한해 변경했다. 상세 계약은 [사진 추출 API](measurement-extraction-api.md)를 따른다. 2026-09-23 결정으로 간이 자가측정 저장과 종목 평가를 추가했다. 기존 건강체력 4요소 레이더 그래프가 저장 가능한 측정 항목을 제한하지 않도록 한다. 전체 프로필의 시각화는 후속 기능에서 정리한다.

## 2. 공식 측정 영역

공식 표의 계층은 **구분(대분류) → 요인 → 측정 항목**이다. 신체조성을 포함한 요인은 청소년 8개, 성인 7개다. 건강체력·운동체력만 세면 각각 7개와 6개이며, 기존에 이야기한 4개는 건강체력의 요인 수다.

| 대분류   | 청소년의 요인                      | 성인의 요인                        |
| -------- | ---------------------------------- | ---------------------------------- |
| 체격     | 신체조성                           | 신체조성                           |
| 건강체력 | 근력, 근지구력, 심폐지구력, 유연성 | 근력, 근지구력, 심폐지구력, 유연성 |
| 운동체력 | 민첩성, 순발력, 협응력             | 민첩성, 순발력                     |

출처: [국민체력100 청소년 측정항목](https://nfa.kspo.or.kr/reserve/2/selectMeasureItemListByAgeSe.kspo), [국민체력100 성인 측정항목](https://nfa.kspo.or.kr/reserve/3/selectMeasureItemListByAgeSe.kspo).

검사 이름·구분·단위·연령군은 위 청소년·성인 측정항목 표에 근거한다. VO₂max의 단위는 [공식 인증기준 표](https://nfa.kspo.or.kr/reserve/0/selectMeasureGradeItemListByAgeSe.kspo)에서 추가 확인했다.

이 목록을 합산하면 청소년·성인 각각 15개 항목, 두 연령군의 합집합은 19개다. 이는 **대체 검사까지 나열한 카탈로그 수**이며, 한 사람이 반드시 15개 검사를 수행하거나 전부 입력해야 한다는 뜻이 아니다. 카탈로그 개수를 저장 조건이나 인증 판정으로 사용하지 않는다.

실제 결과표의 추가 보조값·시도별 값까지 전부 확인한 것은 아니다. 향후 결과표 표본에서 별도 항목이 확인되면 검사 정의와 출처를 추가한다. 절대악력(kg)을 상대악력(%) 필드에 넣는 식으로 기존 항목에 억지로 맞추지 않는다.

## 3. 저장할 데이터

### 측정 기록 한 건

한 건은 **한 사용자의 한 측정 회차**다. 여러 날의 검사값을 한 기록으로 합치지 않는다.

| 필드                     | 저장 시 조건             | 의미·처리                                                                     |
| ------------------------ | ------------------------ | ----------------------------------------------------------------------------- |
| `id`                     | 서버 생성                | 기록 식별자                                                                   |
| `userId`                 | 인증 정보에서 서버 결정  | 요청 본문의 사용자 ID를 소유자로 신뢰하지 않음                                |
| `measuredOn`             | 필수                     | 실제 측정일. `YYYY-MM-DD` 날짜로 저장하고 등록 시각과 구분                    |
| `ageAtMeasurement`       | 필수                     | 측정 당시 만 나이. 현재 나이로 과거 결과를 분류하지 않음                      |
| `sexAtMeasurement`       | 값 또는 `null`           | 결과표 평가에 쓰인 성별 분류. 모르면 추정하지 않고, 이를 요구하는 분석을 보류 |
| `reportKind`             | 선택, 미입력은 `unknown` | `standard`(일반 체력측정), `simple`(공식 간편측정), `unknown`                 |
| `centerName`             | 선택                     | 결과표에 기재된 측정 시설명                                                   |
| `reportedOverallGrade`   | 선택                     | 결과표에 적힌 원문 등급. 서비스가 계산한 등급과 분리                          |
| `sourceProgram`          | 서버 설정                | 이번 범위에서는 `nfa100`. 기관 확인 완료를 뜻하지 않음                        |
| `entryMethod`            | 선택, 기본 `manual`      | `manual` 또는 `self_assessment`                                               |
| `catalogVersion`         | 필수                     | 입력·검증에 사용한 검사 정의의 버전                                           |
| `revision`               | 서버 관리                | 수정 시 증가. 이전 분석 결과가 수정된 입력을 덮어쓰지 않도록 함               |
| `createdAt`, `updatedAt` | 서버 생성                | UTC 시각. 측정일과 다른 의미                                                  |
| `items`                  | 유효한 항목 1개 이상     | 아래 측정값 목록                                                              |

측정일·나이와 한 개 이상의 유효한 측정값을 저장 최소 조건으로 둔다. 신장·체중·원문 등급 등 개별 검사값을 일괄 필수화하지 않는다. 성별 미입력은 저장을 막지 않지만 성별 기준을 요구하는 평가에는 사용할 수 없다.

국민체력100의 공식 간편측정은 자가측정과 다르다. 청소년·성인은 근력과 심폐지구력 중심의 두 항목을 측정하며, 체력인증서는 발급되지 않는다고 안내한다. 이 기록도 확인된 검사 방법·단위로 입력할 수 있으면 부분 기록으로 저장한다. 안내에 악력기라고 적혀 있다는 이유로 kg 값을 %로 해석하지 않는다. [공식 간편측정 안내](https://nfa.kspo.or.kr/measure/simple/selectMeasureSimpleView.kspo)

### 항목별 측정값

| 필드              | 저장 시 조건 | 의미·처리                                                                                              |
| ----------------- | ------------ | ------------------------------------------------------------------------------------------------------ |
| `measurementCode` | 필수         | 카탈로그에 등록된 검사 방법 식별자                                                                     |
| `value`           | 필수         | 사용자가 확인한 수치. HTTP에서는 10진수 문자열로 전송하고 소수값을 보존하며 공란을 0으로 변환하지 않음 |
| `unit`            | 필수         | 카탈로그의 검사 단위와 일치해야 함                                                                     |
| `reportedGrade`   | 선택         | 해당 항목의 결과표 원문 등급이 있으면 보존                                                             |

저장한 값은 사용자가 직접 입력하거나 사진 추출 초안을 확인한 국민체력100 결과다. 기관 서버를 통해 진위를 검증했다고 표시하지 않는다. `entryMethod`는 기존 `manual`을 유지하고 OCR 출처용 DB 변경은 하지 않는다. 사진 추출은 메모리에서 처리하며 원본 이미지 저장소를 추가하지 않는다.

### 검사 정의와 분석 결과의 분리

검사 카탈로그는 `code`, `label`, `category`, `factor`, `unit`, `valueType`, `supportedAgeGroups`, `sourceUrl`, `checkedOn`, `version`을 관리한다. 프론트 입력 폼과 서버 검증이 같은 버전의 정의를 사용하도록 한다. 저장된 기록이 참조하는 정의를 수정·삭제하여 과거 값의 의미를 바꾸지 않는다.

공식 목록의 조회일은 공식 기준의 시행일과 같지 않다. 카탈로그 버전과 평가 기준 버전을 구분한다. 확인된 검사명·단위·연령 범위를 버전이 있는 기준 데이터로 관리하는 것은 결과 하드코딩에 해당하지 않는다.

분석 결과에는 최소한 `measurementId`, `measurementRevision`, `ruleVersion`, `status`, `reason`, `computedAt`을 연결한다. 원문 값·원문 등급을 분석 점수나 게임의 EXP로 덮어쓰지 않는다.

## 4. 입력·검증 규칙

1. 기록은 로그인한 본인에게만 연결한다. 소유권 확인은 모든 조회·변경 경로에 적용한다.
2. `measuredOn`은 실제로 존재하는 날짜이고 서비스 기준일(한국 시간)보다 미래가 아니어야 한다. 근거 없는 과거 날짜 제한은 추가하지 않는다.
3. `ageAtMeasurement`는 정수이며 이번 지원 범위인 13–64세여야 한다. 18세와 19세의 항목 분기를 확인한다.
4. 성별은 결과표의 남/여 분류에 대응하는 코드 또는 `null`로 저장한다. 이름·사진·계정 정보로 추정하지 않는다.
5. 입력된 모든 항목의 코드·연령군·단위·숫자 형식을 서버에서 검증한다. 하나라도 잘못된 경우 필드별 오류를 반환하며 일부만 몰래 저장하지 않는다.
6. 회 단위 항목은 0 이상의 정수로 받는다. 실제 수행하지 못한 0과 미입력을 구분한다.
7. 신장·체중·허리둘레·BMI·VO₂max·시간 측정값은 양수로 받는다. 상대악력·체지방률·제자리 멀리뛰기는 0 이상으로 받으며, 체지방률은 100 이하인지 확인한다. 유연성은 음수가 될 수 있는 부호 있는 수치로 보존한다.
8. `%`라는 이유만으로 상대악력에 100 상한을 적용하지 않는다. 생리학적 정상 범위나 이상치 경계는 별도로 검증된 자료 없이 만들지 않는다. 위 규칙은 입력 형식·값 의미의 검증이며 건강 판정이 아니다.
9. `NaN`, 무한대, 숫자로 해석할 수 없는 문자열은 거부한다. 초 단위의 작은 소수 등 유효한 정밀도를 반올림해 버리지 않는다.
10. 같은 기록에서 같은 검사 코드를 중복 저장하지 않는다. 결과표의 대표 결과값을 입력하며, 시도별 여러 값의 선택·평균 계산을 임의로 수행하지 않는다.
11. 같은 요인에 속해도 서로 다른 검사값은 함께 보존할 수 있다. 트레드밀과 스텝검사 값을 자동 평균하거나 한 항목으로 치환하지 않는다.
12. 신장·체중으로 BMI를 계산할 수 있더라도 원문 BMI 필드를 자동으로 채우지 않는다. 파생값 계산을 추가할 때는 입력값 참조와 계산식 버전을 별도로 둔다.
13. 같은 날짜라는 이유로 서로 다른 회차를 자동 합치지 않는다. 동일 저장 요청의 재시도에 대해서는 사용자별 요청 식별자를 이용해 중복 생성하지 않도록 API를 설계한다.
14. 지원하지 않는 항목·단위는 가까워 보이는 검사에 자동 매핑하지 않는다. 입력을 유지하고 어떤 항목이 지원되지 않는지 알린다.

## 5. 부분 저장과 분석 상태

저장 성공과 분석 가능 여부는 별개다. 키·몸무게만 있어도 유효한 측정값이 있으면 저장할 수 있지만, 그 사실만으로 근력·심폐지구력 점수를 생성하지 않는다.

| 상황                                            | 저장                    | 분석·표시                                             |
| ----------------------------------------------- | ----------------------- | ----------------------------------------------------- |
| 유효한 항목 1개 이상, 기본 식별값 입력          | 허용                    | 저장된 항목 표시. 검증된 분석 규칙이 있는 항목만 분석 |
| 한 개도 입력하지 않음                           | 거부                    | 측정값 입력 요청                                      |
| 해당 연령군에 적용되지만 입력하지 않은 항목     | 다른 항목으로 저장 가능 | `missing` / 미입력                                    |
| 해당 연령군의 카탈로그에 없는 요인·검사         | 입력 대상에서 제외      | `not_applicable` / 해당 없음                          |
| 값은 있지만 평가에 필요한 성별·기준 자료가 없음 | 허용                    | `not_evaluated` / 평가 근거 부족                      |
| 분석 대기 또는 실패                             | 입력 기록 보존          | 처리 상태·재시도 경로 제공. 임의 점수 생성 금지       |
| 분석이 완료됨                                   | 원문과 별도 보존        | 사용한 입력 revision·규칙 버전과 결과 연결            |

성인 기록에 협응력이 없다는 이유로 불완전 기록이라고 판단하지 않는다. ‘한 요인에 값이 있음’, ‘건강체력 4요인이 입력됨’, ‘공식 인증 요건 충족’은 서로 다른 상태다. 단일 `isComplete` 값으로 묶지 않는다.

현재 등록은 **입력 → 검증 → 공식 종목 평가 → 함께 저장 → 조회**까지 수행한다. 확인되지 않은 공식 기준은 사유와 평가 불가 상태를 반환한다. 미입력 요인을 0점으로 넣어 그래프를 완성하지 않는다.

수정하면 revision을 갱신하고 이전 revision의 분석을 현재 결과로 사용하지 않는다. 후속 분석에서도 각 측정 회차의 값과 revision을 분리해 다뤄야 한다. 2026-09-21 정정으로 사용자 프로필의 currentFitness 응답과 개인별 목표값 기능은 폐기했다. 기존 측정 CRUD는 유지하고 유효한 기록 존재 여부만 온보딩에 사용한다. [사용자 API](users-api.md)를 따른다.

## 6. 구현 검증 기준

- 13·18세에는 청소년 항목, 19·64세에는 성인 항목을 제공하고 서버도 같은 기준으로 검증한다.
- 한 항목만 입력해도 저장·재조회되며, 다른 항목은 미입력으로 남는다.
- 청소년의 반복점프와 성인의 교차윗몸일으키기를 혼동하지 않는다.
- 20m 왕복오래달리기 횟수, 트레드밀 VO₂max, 스텝검사 VO₂max가 서로 독립적으로 보존된다.
- 유연성 음수, 실제 0회, 반응시간 소수가 올바르게 보존되고 빈 문자열은 0이 되지 않는다.
- 상대악력의 단위에 kg를 넣거나 성인 항목에 청소년 전용 검사를 넣으면 해당 필드 오류가 반환된다.
- 다른 사람의 기록을 ID만 바꿔 읽거나 수정할 수 없다.
- 요청 재시도가 중복 기록을 만들지 않고, 수정 전 분석 결과가 새 기록에 붙지 않는다.
- 기준표·외부 데이터가 없거나 장애가 나도 가짜 점수·추천·성공 응답으로 대체하지 않는다.

DB 계층과 HTTP API는 실제 PostgreSQL 통합 테스트로 검증한다. 계정 참조, 최소 한 항목, 연령·단위·수치 형식, 음수·0·소수 보존, 본인 접근 권한, 생성 재시도 중복 방지, 수정 충돌·revision 증가, 삭제와 페이지 조회를 검증한다. 실제 분석 결과와 revision 연결은 후속 분석 구현 범위다.

## 7. 후속 단계로 넘기는 항목

- **DB·CRUD 구현 완료:** PostgreSQL 17·Prisma 7.10, 버전별 검사 정의·측정 회차·항목 테이블, 제약·인덱스·마이그레이션, 공개 카탈로그 조회와 본인 기록 CRUD API. 측정값은 고정 소수 자릿수로 반올림하지 않는 PostgreSQL NUMERIC으로 저장한다.
- **프로필 생성 작업:** 공식 기준표의 전체 범위·적용 시점 검증, 요인별 해석, 복수 대체검사의 대표값 정책, 레이더 그래프 환산·표시 방식. 기준이 없으면 미평가 상태를 유지한다.
- **실제 결과표 대조:** 공식 측정항목 표와 공공기관이 공개한 성인 체력평가지 예시를 확인했다. 예시에는 실제 측정값, 항목별 평가, 종합등급이 구분되어 있다. 청소년·모든 센터의 최신 결과표 양식과 부가값까지 검증한 것은 아니다. 확인 범위와 출처는 [체력평가지 검토](nfa100-report-review.md)를 따른다.
- **등급 자동 판정:** 공식 수치 기준표뿐 아니라 종합 인증 조건과 시행일을 함께 검증한다. 청소년·성인의 종합 인증등급은 2025-06-02부터 6등급까지 확대되었으며 과거 결과에 소급 적용하지 않는다. 항목별 평가와 종합 인증등급을 같은 열거형으로 취급하지 않는다. 현재는 원문 등급 보존만 구현되어 있다.
- **지원 연령 확대:** MVP 이후 개발한다. 현재 지원 연령인 만 13–64세를 유지한다.
- **운동 연계:** 영상 저장·조회, 추천, 내부 가중치 갱신은 현재 측정 데이터 단계 이후에 진행한다.
- **제품 전체 입력 정책:** 측정 기록이 없는 사용자의 온보딩·운동 이용 경로. 2026-09-23부터 저장 완료된 간이측정도 유효한 기록으로 센다. 사진 추출 초안이나 간이측정 진행 화면만으로 온보딩을 완료하지 않는다.

현재 입력 구조를 진행하기 위해 추가로 필요한 사용자 결정은 없다. 후속 분석 규칙은 근거 자료를 확보해 별도로 구체화한다.
