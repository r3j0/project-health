# 02번 프론트엔드 검증

검증일: 2026-09-21. 브랜치: `codex/frontend-phase-two`.
백엔드: PR #6의 `898b2a480d37438ed55ca1860fe519cc732fd695`, 전용 로컬 PostgreSQL.
프론트엔드: Next.js 16.3.5 프로덕션 빌드, Node.js 26.7.0, Chromium 모바일 환경.

## 목표 달성 판정

현재 백엔드 계약으로 연결할 수 있는 기능 및 2026-09-21 추가 요청의 성인 간이측정 실행·저장을 구현했다. 회의의 02번 전체 목표를 완료했다고 판단할 수는 없다. 사진 자동 추출, preference 저장, 커리큘럼 자동 배정·실행에 필요한 API가 없고, 다각형 프로필·리포트·내비게이션 확장은 요청에 따라 제외했다.

`isOnboarded`는 별도 온보딩 단계가 아니라 실제 측정 기록의 존재 여부다. 성인 간이측정을 실제 저장하면 `true`로 갱신된다. 저장하지 않은 측정 진행은 등록으로 간주하지 않는다. `currentCurriculum`은 정의의 ID·이름과 배정 상태만 제공하므로 실제 운동 시작을 활성화하지 않는다. 배정/완료 화면 검증에는 명시적 HTTP 응답 fixture를 사용했다.

## 재현하여 수정한 문제

1. **운동 진행 되돌아감:** 기존 저장값이 있는 상태에서 저장소 쓰기가 실패하면, 최신 메모리 값보다 과거 저장값을 우선 읽었다. 최신 메모리를 기준으로 복원하도록 수정했다.
2. **폐기한 초안 재등장:** 저장소 삭제가 실패하면 로그아웃·초안 폐기 후 운동/측정 입력이 다시 복원될 수 있었다. 삭제 표시를 메모리에 유지하고, 저장소 삭제만 실패한 경우에는 빈 값으로도 덮어쓴다. 저장소 접근이 전부 막힌 환경의 보장은 같은 문서 안으로 한정된다.
3. **계정 변경 결과 불확실 시 복구 동선 부재:** 서버 변경은 성공했으나 브라우저 응답만 유실되면 재로그인 안내만 보였다. 중복 제출을 잠그고 `다시 로그인하기`를 제공한다. 선택 시 모든 탭의 로컬 인증·초안을 정리한다. 현재 비밀번호 오류는 자동 재전송하지 않으며 입력 수정 후 재시도할 수 있다.

회귀 테스트는 수정 전 실패를 확인한 뒤 추가했다. 탈퇴 응답 유실은 서버가 처리한 경우와 처리하지 않은 경우를 각각 검증하며, 재로그인이 실제 서버 결과를 따르고 탈퇴 요청이 반복되지 않는지 확인한다.

## 이전 02번 검증 결과

- 단위 테스트: 38개 통과.
- 브라우저 E2E: 두 번째 검증의 최종 수정본 전체 50개 통과 (3.6분).
- ESLint, TypeScript, Prettier, 프로덕션 빌드 통과.
- 실제 API로 가입·로그인·갱신·로그아웃, 계정 변경·탈퇴, 측정 CRUD와 온보딩 반영을 확인했다.
- 응답 지연·유실·401/403/409/412/429/503, 중복 제출, 다중 탭, 계정 전환, 초안 만료·저장소 실패, 화면 이탈·히스토리 이동·새로고침을 검증했다.
- 320px 너비에서 주요 6개 화면의 가로 넘침을 확인했고, 운동 하단 버튼을 스크롤 후 클릭해 고정 메뉴에 가려 막히지 않는지 추가 검증했다.
- 사진은 화면 이탈 시 폐기되는 것이 정상이다. 사진으로 입력하던 측정 초안은 `사진 없이 직접 입력하기`에서 복원된다.
- 인증 요청 제한은 해제하지 않았다. 02번 E2E 파일은 이전 파일의 요청량 때문에 실패하지 않도록 다음 분의 제한 구간부터 시작한다. 최초 검증에서 발생한 429와 접근성 알림 선택자 중복은 테스트 실행 문제로 수정했다.

## 두 번째 검증에서 추가로 재현한 문제

기존 47개 E2E는 다시 모두 통과했지만, 추가한 세 시나리오는 수정 전 프로덕션 빌드에서 모두 실패했다.

- **저장 응답 유실:** 서버에 첫 측정 기록이 저장되어도 메인은 계속 미등록으로 안내했다.
- **마지막 기록 삭제 응답 유실:** 서버에서 기록이 삭제되어도 메인은 등록된 상태로 남았다.
- **화면 복귀 갱신 누락:** `visibilitychange`만 발생하고 `focus`가 없는 복귀에서는 다른 기기에서 만든 기록을 반영하지 않았다. 실제 기기를 대신해 브라우저 이벤트로 재현했다.

측정 변경 요청의 통신 오류·서버 오류에서도 같은 로그인 세션에 한해 `/auth/me`를 다시 조회한다. 등록 여부를 낙관적으로 바꾸거나 변경 요청을 자동 재전송하지 않는다. 기존 폼의 미확정 요청·중복 방지 키는 유지한다. 사용자 상태 공급자는 `focus`와 `visibilitychange` 모두에서 현재 화면이 보일 때 갱신한다.

추가 회귀 테스트는 `tests/e2e/phase-two-profile-recovery.spec.ts`에 있으며, 실제 서버 저장·삭제 후 브라우저 응답만 유실시키고 변경 요청이 한 번만 전송되는지 확인한다.

## 검증 한계

실제 iOS/Android 카메라·키보드와 Safari는 이번 자동 검증 범위에 포함하지 않았다. 사진 자동 추출, 실제 추천 알고리즘, 커리큘럼 실행·보상 지급은 동작한다고 간주하지 않는다. 후속 API 계약이 정해지면 그 계약에 맞춘 연동 검증이 필요하다.

## 성인 간이측정 추가 검증 (2026-09-21)

PR #6 백엔드에 이 브랜치의 `self_assessment` 생성/수정 검증과 추가 카탈로그 마이그레이션을 적용한 로컬 PostgreSQL 환경에서 검증했다.

- 만 19~64세, 근지구력 검사 하나 선택, 항목 건너뛰기, 공란/실제 0/음수 구분.
- 3초 준비 후 교차 윗몸일으키기 60초, YMCA 180→60→10초 자동 연결 및 맥박×6 환산. 콜백 지연에도 경과 시간 기준을 유지한다.
- 중단·숨김·새로고침은 현재 측정 시도를 무효화한다. 이전 입력값은 유지한다. 체력검사를 일시정지해 계속한 결과를 저장하지 않는다.
- 부분 기록 생성·자가측정 출처·기록 수정·온보딩 갱신, 응답 유실/재로그인 후 원래 생성 키·본문 유지와 중복 방지.
- 화면 이탈·재진입, 24시간 초안 만료, 저장소 실패, 계정 전환/로그아웃의 초안 격리.
- 신장·체중 수정/삭제에 맞춰 BMI 재계산/제외. 미입력 자료로 값이나 점수를 만들지 않는다.
- 모바일 측정 중 하단 메뉴가 박자 안내를 가리는 문제를 발견해 측정 중 메뉴를 숨기고 타이머/중단 버튼을 같은 뷰포트에 배치했다.

실제 iOS/Android 기기의 소리 출력과 화면 잠금 동작은 검증하지 않았다. 브라우저 소리 안내는 선택 기능이며 시각적 박자 안내가 함께 제공된다. 일반 운동 추천, 서버 배정 완료 처리 및 보상 지급은 구현됐다고 간주하지 않는다.

최종 검사 결과:

- 프론트엔드 단위 테스트 43개 통과.
- 브라우저 E2E 전체 59개 통과(4.5분), 이후 완료 화면의 새 측정 시작 추가 사례 1개 통과. 총 60개 시나리오.
- 백엔드 단위 테스트 46개, 격리 DB/API 통합 테스트 111개 통과. 추가 마이그레이션 적용 후 재실행 시 미적용 항목이 없는 것도 확인.
- 프론트엔드 ESLint·TypeScript·Prettier·프로덕션 빌드 및 백엔드 린트·타입·빌드 통과.
- 전체 검사 최초 실행의 1건은 로컬 인증 요청 제한(429)으로 정지했다. 간이측정 테스트 파일도 다른 인증 테스트와 같은 방식으로 새 제한 구간에서 시작하도록 분리한 뒤 모두 통과했다. 제한은 해제하지 않았다.
- 수정한 로컬 서버를 실행한 상태이며, 실제 사용자 계정에는 테스트 측정값을 저장하지 않았다. E2E의 전용 테스트 계정/로컬 DB를 사용했다.
